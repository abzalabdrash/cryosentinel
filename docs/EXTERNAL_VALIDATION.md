# External Validation

This page tracks independent runs of the released CryoSentinel checkpoint outside the v1.0 High Mountain Asia validation and test splits.

No external validation results have been submitted yet.

## How To Contribute A Result

Please open an issue or pull request with:

- The region and acquisition year.
- The data source and preprocessing path.
- The exact checkpoint and command used.
- Per-chip diagnostics, if available.
- Aggregate metrics, including IoU and any known label-quality caveats.

We will list accepted results here with attribution and enough metadata for another reader to understand the protocol.
